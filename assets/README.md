# assets · 成果（游戏运行时资产）

> 插件按 URL `/nitian-assets/` 读这里。**路径是运行时硬引用，子目录名别乱动**；改动要走任务书并重启 DSH 插件。

| 子目录 | 中文名 | 放什么 |
|---|---|---|
| `realms\` | 境界资产 | 每境的 **三件套**：`bg.webp`(背景16:9) / `hero.webp`(海报3:4) / `wanglin.png`(角色立绘，含透明) |
| `character\` | 角色立绘 | 各角色的站桩/立绘 |
| `enemies\` | 敌人 | 敌人/心魔立绘 |
| `officials\` | 官员 | 官员/官职素材 |
| `ui\` | 界面资产 | 印章 / 立绘 / 背景 / 分身等界面元素 |
| `animations\` | 动画/视频 | 破境、过场、境界背景视频 |

## 分类口诀
按**职责**分，不是按境界堆。角色/敌人/官员/界面/动画各归其位；
每境核心资产认准 `realms\<境界id>\` 三件套。

## 资产契约真源
运行时按 `workers/asset-manifest.schema.json` 决定怎么取用（真源在引擎侧）。
