# preview · 预览层

> **这里是「给人看的展示层」，不是第二份成果库。**
> 八字铁律：`assets/` = 正式成果本体；`preview/` = 正式成果 + 过程物一切「为了给人看」的整理结果（复制 / 缩略 / 拼图 / HTML 展示 / 文档阅读视图），**永远不作游戏运行时引用**。

## 三层分类（防放错，认目录名即可）

| 层级 | 目录 | 放什么 | 举例 |
|---|---|---|---|
| ① 成果预览 | `成果预览/` | **已验收正式成果**给人先看的展示（界面模本 / 拼图 / 缩略 / HTML 演示） | `元婴期-界面模本.jpg`、`结丹期-界面模本.jpg` |
| ② 任务/项目预览 | `任务预览/` | **单个任务或阶段性项目**的可视预览（工作流截图、阶段成果拼图、演示页） | 各制作需求任务的阶段性展示（空即待补充） |
| ③ 文档预览 | `文档预览/` | **某份文档的阅读视图**——把设计意图、回复、代拟正文渲染/归纳成给人读的整理页 | `王林留白空间-设计意图确认.md` |

## 一键归属规则

- **它是「正式成果的展示」** → `成果预览/`
- **它是「某个任务/项目阶段性做了什么」** → `任务预览/`
- **它本质是「把一份文档给人生读」** → `文档预览/`
- 都不沾 → 别放这里，回 `docs/` 或 `workers/待验收/`。

## 与 `docs/` 的切分（别打架）

- `docs/05-成果与预览.md` 管「**成果在哪 + 怎么看**」→ 它只做**导航**，不存预览本体。
- 本 `preview/` 是预览**本体**的存放地。**导航看 docs/05，本体放 preview/**。

## 怎么看

- 总入口：本 README。
- 想看「这次做出来什么」→ 看 `成果预览/`（模本 / 拼图）。
- 想看「某个任务/项目」→ 看 `任务预览/`。
- 想看「某份文档的阅读版」→ 看 `文档预览/`。
- 想看「运行时在游戏里长什么样」→ `http://127.0.0.1:3080/nitian-assets/`（DSH 插件挂载）。
- 成品资产真身在 `assets/`，账本在 `docs/02-资产清单.md`。
