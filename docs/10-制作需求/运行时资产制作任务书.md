## 一、背景与目标

「逆天主题」需要运行时资产：每个境界的**背景海报(bg)、王林立绘(character，透明底)、主视觉海报(hero_poster)**。
官方海报 v1/v2 已收集进 `D:\逆天主题\workers\officials\`（16 张官方海报，无重复），存量收集在 `workers\collected\<境界id>\`。

**本任务**：把官方海报/存量官方图**转成可直接进引擎的运行时资产**，做抠图、按需超分、转 WebP、按命名规范归档，并填进 `workers\asset-manifest.schema.json` 对应的 `assets` 字段。

> ⚠️ 这不是抄图，是需要**眼睛**的活：每张图要人眼看构图/清晰度/抠像边缘，选最合适一张做对应 slot。所以由你（多模态）执行。

## 二、工作范围
- 只允许在 `D:\逆天主题\` 内读写；原始官方海报的**源文件**不得删改/覆盖，产出新文件。
- 工具可自行在本机调用：Photopea / rembg（抠图）、Upscayl / Real-ESRGAN（超分）、ImageMagick 或 ffmpeg（转 WebP/压缩）。Windows 命令行长命令建议写 .ps1/.bat，Excel/manual 可不用。

## 四、产出规范

1. **目录**：`D:\逆天主题\assets\realms\01_ningshi\`、`04_yuanying\`、`05_huashen\`；`character.png` 透明底、`bg.webp` / `hero_poster.webp` WebP（质量 85~90）。
2. **三件套保留**：每张处理图若需要，保留 `MASTER PNG`（`assets\realms\<id>\raw\`）+ `RUNTIME WEBP` + `THUMB JPG` 三份；不改/不覆盖原始官方海报。
3. **填 manifest**：把每个境界产出路径填进 `workers\asset-manifest.schema.json` 里对应 realm 的 `assets.bg / assets.character / assets.hero_poster`（`transition_video`、`bgm`、`sfx` 本轮先留 `null`/不动，后续另派音频任务）。
4. **核对名字**：`character` 必须透明底（引擎叠在海报上）；不透明就用 rembg/Photopea 处理干净。

## 六、纪律
1. **源文件只读**：不改不删 `workers\officials\` 与 `workers\collected\` 任何原始图。
2. **透明底要真透明**：发丝/边缘不干净的 PNG 会被退回返工。
3. **比例不失真**：裁切或补背景，禁止拉伸变形。
4. **命名规范**：`bg.webp` / `character.png` / `hero_poster.webp`，放对应 `assets\realms\<id>\`。
5. 汇报写完才算结束；之后主管会把真负责音频/生图的另外派。
