# UI 树状层级与呈现结构

> 版本：v0.1（2026-09-04 · 依据 GPT 镜像版 Extended（vip-22）读仓优化产出，原文 `C:\Users\Public\nitian_ui_tree.txt`）
> 定位：回答「**产品呈现结构**」+「**插件 UI 层级树（主界面→二级→三级→四级）**」——每天睁开眼睛看到什么、点开能到哪、每层放什么、怎么交互、怎么接故事。
> 对齐：对应 **A1 Gate · 化神→婴变纵切**（婴变期为主导）、方案 C 双层、三类状态边界、双轴解耦。A2+ 一律标**后置**，A1 只做能验证「Coding 当下有天气、Token 长线有命运」这条闭环保必做项。

---

## 0. 取舍原则（三句，先立规矩）

1. **不是页面越全越好**。任何节点若不能帮助证明 A1 闭环（即时回响"此刻在修仙" + Token 长线"持续在修仙"），就只留 voice 空壳或直接标 A2+。
2. **状态边界严固定**：境界/修为/pct 是可推导态、只读不改；外观/开关是用户持久态；即时演出、事件痕迹只活本 Session。四窗世界状态随时由 realmId+pct 重建，一次性跨窗演出不补播、不落长期存档。
3. **收敛编排，不是再造一套导航**：现有插件已有境界章、灵力条、王林陪伴、3D、设置面板、编年史卷轴、破境层等结构——A1 把它们重新编排进下面这棵树，不为 UI 树另开资产生产线。

## 2. 主界面：A1 信息密度裁定（五信号压成三视觉区）

> **默认只看到两块常驻 + 一块事件临时出现。正常 Coding 90% 时间只有两块静态信息。**

| 视觉区 | 内容 | 判定 |
|---|---|---|
| **① 修为骨架** | 境界章（显示化神/婴变）+ 灵力条（用填充表推进，不印裸 73.2%）+ 当前窗位词/四段刻度 | 必需，但合并成一张卡，不拆三张 |
| **② 王林相位** | 极小尺寸、可收起的当前形态立绘（复用 era_05 化神 / era_06 婴变 现成相位，不新开产线） | 必需，因为"陪伴"是一级体验目标 |
| **③ 即时反馈带** | 平时**完全为空**；error/tool/thinking/task_complete 到来才浮出（敌影/法宝虚影/闭关徽记/任务收束），1~数秒自行消退 | 必需，这就是方案 C 的**即时层**，不能做成长期消息中心 |

**A1 默认不常驻**：仙玉资产、真/演 Token 分拆、3D 按钮、大段语录、完整故事卡、任务列表、敌人图鉴、关系值、成就数、声音状态。

**展开/收起逻辑**：鼠标离开/持续 Coding 保持默认；点击境界/进度才展开侧抽屉；王林默认小相位，点击才进洞府；临界 90–100% 只能增强呼吸/裂纹/微震等环境信号，**绝不自动扩 UI、不弹窗、不遮代码**。

## 3. 关键节点：交互 + 故事逻辑（每层一句话落点）

### 修为·行路详情（A1必做）
- **用途**：讲清「我为什么现在处于这里、下一步会发生什么」。点击境界章/修为条/窗位进右侧抽屉，Esc/点空白/再点退出，全程不离开 DSH、不做全屏。
- **故事**：不是经验值详情，而是一张「这一世已走到哪」的行路图；境界来自 realmId、故事素材来自 chronicleKey，**UI 绝不因两者当前碰巧对上就写死成同一 ID**（双轴是冻结不变量）。
- **四窗行路图**：默认四段入世→因起→劫至→临界，过去点亮、当前强调、未来压暗，只读不能跳进度。窗位只由 realmId+pct 决定。
- **当前窗 Beat 详情**：只解释当前一步；一句 hint + 1~2 个 Canon refs；内容从 Canon 引用，**不在 UI 另写第二份剧情**。
- **A1 验真栏**：给单兵验证的隐藏诊断层，默认折叠，入口很弱。四级「双轴/状态来源读数」同时看 realmId/chronicleKey/pct/当前window/Token source/最近标准事件，全只读——保证开发者能核对双轴与三类状态没串线。

### 王林洞府（占位 voice）
- 未来承载「我这个王林是谁」；A1 只展示大图+当前境界+当前相位+一句状态，点关闭返回。强调「用户即王林」，不是抽卡角色详情。相位由可推导境界决定，**不允许 Journey 临时角色永久换掉用户王林**。

### 行路卷轴 / 逆天修行录（占位 voice）
- 让想主动读故事的人「点开看全」，不承担日常 Coding 的叙事推进。主界面负责「故事主动渗出」，卷轴只负责「我想回头细看」。化神→婴变切换换的是故事素材映射，不改变 realmId 职责。

### 事件回响（占位 voice）
- A1 不能把即时层变成通知中心。即时反馈带已负责真正体验；此入口存在也只展示「本 Session 最近几次回响」，**刷新即空**。报错=遇劫、tool=法宝、thinking=闭关、task_complete=此劫已过，但**不改 Canon、不改境界、不自动成为履历**。

### 道藏 / 伴生设置（A1必做）
- 保证修仙体验始终可退让给 Coding。点「道」展开小面板，退出即保存。**伴生模式**只留最必要项：Journey 开/关、王林常驻/极简、即时回响正常/静默——关闭的是表现，不是修为事实。**演练验真**：隐藏开发折叠项，可注入 demoToken、模拟标准事件、跨四窗、复位测试值，**不进入正式存档、不伪装成玩家修为**——让 A1 Gate 几分钟内重复验证，而不是等真实 Token 数周推进。

### 破境演出层（A1必做，系统触发，非导航页）
- **不是导航页面**：只有真实/测试 Token 达到化神→婴变阈值才进入，正常无任何「进入破境页」按钮。这是方案 C 两层第一次合流：无数 Coding 天气累积在长线修为上，最终完成命运层变化（总设：仪式感，不是 99 跳 100）。
- **临界异象**：90–100% 时提前示警，无点击，境界章呼吸/裂纹/微震随增强，绝不弹窗。
- **破境主演出**：阈值准确触发全屏演出；正式体验不靠用户手动选境界；开发验真可人工触发。是全产品唯一允许暂时压过 Coding 视野的时刻。
- **Aftermath · 新卷展开**：避免演出结束一刀切回 IDE。旧化神卷呈现「已历」视觉结果，新 realmId=婴变生效并映射取得新 chronicleKey，**只泄露新卷第一条线索，不一波倒完婴变剧情**。Aftermath 是 Session 演出；能由境界推导的「旧境已历」不额外造持久状态。
- **婴变首屏 / 回 Coding**：展示婴变境界章、新王林相位、新窗位=入世、一句 Journey hint，随后淡出恢复默认伴生态。**闭环必须收在 Coding→修仙→破境→回 Coding**，不是破境后送进另一套游戏菜单。

## 4. A1 必开页面清单 / 后置清单

**A1 必开**：主界面、修为·行路详情（含四窗行路图 + 验真读数）、道藏最小设置/演练验真；另有系统触发的临界→破境→Aftermath 演出层。

**后置（A2+）**：王林洞府完整化、事件回响历史、劫痕永久图鉴、完整编年史浏览、外观/本尊分身管理、3D、关系/资产/成就、声音与全量皮肤深化。

---

## 5. A1 最大风险（写下来防漂移）

> 把「四窗 + 即时回响」做成**一堆可点击、可收藏、可持久化的页面**，最终得到一个**修仙 Dashboard**，却没有证明「Coding 当下有天气、Token 长线有命运」这条唯一闭环；尤其**事件 Session 态一旦混进永久履历**，同时破坏方案 C 和三类状态边界。
