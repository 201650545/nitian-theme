# 逆天主题（仙逆）游戏项目总览

> `docs/` 是项目唯一事实来源（Single Source of Truth）：任务、资产、规格、协作规约全在这里。
> 成品图/视频等大文件一律不入 git（见 `.gitignore`），仓库里只有代码与文档。

## 一句话

《仙逆》主题的修仙养成网页游戏，深度联动原著境界体系（炼气→筑基→结丹→元婴→化神→问鼎），由本地 Agent（Qoder）+ GPT 美术总监协作生产资产，人类拍板方向。

## 协作分工

- **Qoder（本地 Agent）**：任务编排、批量发送与提取落盘、验收、本仓库与 docs 维护
- **GPT（美术总监，vip-14 镜像站）**：读本仓库掌握项目全貌 → 自主设计提示词 → 出图打包交付
- **人类**：拍板方向、目检关键资产、验收
