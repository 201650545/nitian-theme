# 逆天 · 修道×Coding 动态情景交互系统 — 设计方案

> 版本：v1.0（2026-08-15 定稿）
> 目标载体：DeepSeek Harness（DSH）网关 `127.0.0.1:3080`
> 性质：个人专属沉浸式 Coding 体验系统，仅本地使用，不发布

---

## 一、设计思路

### 1. 核心理念

**不是给 DSH 换皮肤，而是做一个「轻量修真养成游戏引擎」，事件源换成 coding 行为流。**

- 每次编程会话 = 王林的一段人生
- Token 累计消耗量 = 王林的人生刻度（灵力修为）
- 境界节点 = 人生里程碑
- Coding 的顺境与困境 = 修仙路上的突破与强敌

一句话：**把写代码的过程，活成王林的修道一生。**

### 2. 三条设计法则

1. **线性对应**：王林的故事是线性的。找出故事线上的关键节点（成长、遇敌、得宝、破境），与 coding 数据（Token 累计量、任务阶段、事件类型）一一锚定。
2. **真实沉浸**：视觉素材追求真实感——采用动画真实截图、官方海报、写实立绘，做成「动态电影海报」的质感，而非卡通模拟风格。画面要有故事感、场景感。
3. **全链路演出**：境界不只是数字变化。升级瞬间 = 整张海报电影式转场（旧境碎裂、金光冲屏、新境浮现）+ 角色换装 + 全局换色 + 境界判词落下。

### 3. 情绪设计

- **顺境**：日常修行（吐纳、推演、赶路）——平静陪伴感
- **逆境**：报错、重试、卡壳 = 遇敌受挫——浮现该境界对应的强敌 + 经典台词，激发斗志
- **高潮**：Token 破界、任务完成 = 破境、杀敌、夺宝——全屏演出，仪式感拉满
- **陪伴**：王林作为动态角色常驻界面一角，随用户一起成长，用户即是王林

## 二、故事与数据的映射法则

### 映射总表（引擎层的灵魂）

| Coding 事件 | 仙逆世界事件 | 呈现 |
|---|---|---|
| Token 累计到达节点 | **破境** | 全屏演出 + 换装 + 换场景 + 判词 |
| 报错 / 重试 | **遇敌受挫** | 敌人形象浮现 + 经典台词 |
| 长时间无输出 | **闭关推演** | 角色打坐、灵气涟漪 |
| 工具调用（浏览器/终端/改文件） | **施展法宝** | 神游千里 / 布阵 / 炼器画符动效 |
| 任务完成 | **杀敌夺宝** | 仙玉入账、胜利闪光 |
| API 花费 | **仙玉消耗** | 流水记录 |
| 上下文将满 | **灵力将竭** | 警示涟漪 |

| 元婴期 | 8M – 20M | 罗天星域，纵横一方 |

| 问鼎期 | 100M – 200M | 问鼎巅峰 |

## 三、整体框架（5 层）

| 层 | 职责 | 关键产出 |
|---|---|---|
| **叙事层** | 王林编年史：线性故事节点结构化（每节点：境界/成长事件/敌人/法宝/坐骑/仙玉事件/经典语录/名场面），绑定 Token 锚点 | `编年史.json`（全项目唯一事实源） |
| **资产层** | 全部素材生产与管理 | 图片（真实系+生成系）、视频、3D 角色、文字、演出脚本 |
| **引擎层** | 运行时：监听 coding 事件 → 查叙事配置 → 驱动画面变化 | 事件-状态-渲染管线 |
| **角色层** | 王林伴侣系统：状态机 + 分时期外观 + 装备进化 | 可插拔渲染器（2D→Live2D→3D） |
| **通道层** | 上线 DSH | CDP 试跑 → dsh 原生插件 |

依赖关系：叙事层、资产层可并行 → 引擎层吃两者 → 角色层挂载引擎 → 通道层收尾上线。

## 四、呈现方式

### 1. 总体视觉：动态电影海报

界面主体是一张有王林立绘的境界海报，随境界整体替换：

- **三大件联动**：背景场景 + 主题色 + 进度条位置同步切换
- **换装**：王林立绘按时期更换（青衫少年 → 白衣弟子 → 黑衣杀伐 → 星袍大能……）
- **每境界专属色**驱动全局 UI（按钮、描边、进度条、高亮）
- 境界印章 + 判词（如「结丹 · 灵液化丹，杀伐初显」）

**破境转场演出**（升级瞬间）：旧境画面碎裂 → 金光冲屏 → 新境海报浮现 → 印章落下 → 判词显现。

### 2. 界面命名体系（沉浸式文案）

| DSH 原界面 | 仙逆化命名 |
|---|---|
| 侧栏会话列表 | 洞府（卷轴样式） |
| 对话区 | 论道（助手回复称「道音」） |
| 详情栏 | 道藏 |
| 输入框 | 传讯玉简 |
| 开机加载页 | 王林立绘 +「顺为凡，逆则仙，只在心中一念间」 |
| 加载动画 | 打坐吐纳转圈 |
| 报错提示 | 心魔劫（红色脉冲） |

### 3. 状态栏三仪表

境界徽章 ｜ 灵力条（Token 进度）｜ 仙玉余额（API 额度）

### 4. 动态角色（五态状态机）

| 状态 | 触发 | 动画 |

| 待机 | 默认 | 呼吸微动、衣袂飘 |

## 五、角色成长系统

- **外观进化**：分时期立绘/模型随境界更换
- **装备体系**：武器、法宝（如天逆珠意象用于「时间回溯=撤销/回滚」）、坐骑（后期解锁）
- **仙玉经济**：API 花费 = 仙玉流水，重要操作显性化为「消耗仙玉」
- **经典语录与动作**：关键时期触发（破境、遇大敌、里程碑），台词取自原著/动画，由叙事层 M1 考证后入库

## 七、技术路径

1. **换肤机制**：DSH 全 UI 基于 `--dsw-*` CSS 自定义属性，覆盖根色值即可驱动全局变色
2. **注入通道**：`deepseek-skin-studio` 的 theme.json + CDP 注入（零侵入试跑）→ 稳定后打包 dsh 原生插件
3. **Token 数据源**：读 DSH 用量统计（社区已有实时 Token 统计插件先例），累计值存 localStorage；若不可得，退化为「任务数/代码行数」锚点
4. **派工模式**：写自包含任务书 → 用户转发 Antigravity（谷歌 Pro 会员）→ 产出落 `workers\` → 写 `汇报-Gemini.md` → 主 Agent 读取验收
