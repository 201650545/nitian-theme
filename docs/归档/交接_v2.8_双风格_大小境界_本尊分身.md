## 4. 任务 A（最优先）：大/小境界破境分化

**用户原话**：大境界跨越在原著中很难，应该有更炫酷持久的动画；小境界升级简单点就行。目前表现一样。

现状代码（client.js `enter()` 约 L590-628）：
- 每个境界都从 `BT_VID` 取视频播放，小境界 5800ms / 大境界 7600ms 清场。
- 大境界判定：`const major = i > prev && [3, 6, 10, 18].includes(i);`（结丹→元婴、婴变→问鼎、碎涅→空涅、大天尊→踏天）。
- `.bt.major` CSS 已有震屏/增强闪光（约 L413-418）。

**要做**：
1. 小境界（major=false）：**不播视频**，只保留 flash + ring + newseal + verdict 的短演出，总时长压到 ~2.5-3s（改 L627 的 setTimeout 常量；`.bt.playvid` 分支跳过）。可参考 `assets/animations/bt_minor_demo.mp4` 的节奏感。
2. 大境界（major=true）：保留视频 + 46 粒子 + 震屏，可再强化（延时至 ~9s、加第二波粒子、verdict 更大字）。
3. 注意 04_yuanying/07_wending/11_suinie/19_qiao1 这四境 BT_VID 指向 bt_m/bt_b/bt_p 等电影级视频，全部落在 major 判定内，逻辑自洽，别破坏。

**验收**：① 用面板「＋1B」跨小境界→无视频、≤3s；② 选「元婴期」点入此境→有视频+粒子+震屏；③ demoTokens 复位。

## 5. 任务 B：双风格切换（2D 动漫 / 真人写实）

**用户原话**：要两种风格：1. 2D 动漫风格 2. 真人的炫酷写实风（真人修仙那种真实感）。

- 现有演示素材：`assets/animations/bt_real_demo.mp4`、`bt_2d_anime_demo.mp4`。可先用它们验证切换链路。
- 真人风素材后续按 §7 生成，命名规范：视频 `bt_XX_real.mp4`、立绘 `era_XX_real.png`、背景 `bg_XX_real.jpg`，全部放 `assets/` 对应子目录（不要放 workers）。

**验收**：面板切到「真人写实」→ reload → 破境演出播 real 视频（或回退不报错）；opts 刷新后仍保持。

## 6. 任务 C：本尊/分身

**用户原话**：王林前期不是有本尊和分身吗？这一点你没有把它做上去。

背景：小说前期王林以分身（化名许木/铁柱）行走，本体闭关。当前主题完全没体现。

**方案**：

- 分身按钮只在境界 02~05 区间显示（后期分身已归一，符合原著）。

**验收**：按钮切换生效、图不 404、立牌拖拽/收起功能不回归。
