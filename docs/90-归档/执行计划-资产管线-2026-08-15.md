## 四、落地顺序（首周）

1. **[Day1] 建目录骨架 + 抽 Frame Bank**（ffmpeg 每 2s 一帧，先全片建索引）
   → 命令见 `workers\拆动画四库-命令手册.md`
2. **[Day1] 拆 Audio Bank**（ffmpeg 拆音轨 → 分离 BGM/环境/人声）
3. **[Day2] 建 Shot Bank**（挑「破境/施法/打坐/山水」镜头，剪 2~10 秒片段）
4. **[Day3] 王林 Identity Board**（把 6~12 张最稳参考合成人物板：正/侧/3-4/全身/背面/服装）→ 供 LoRA/IP-Adapter 当 Reference
5. **[Day3] 凝气/元婴/化神 Hero Visual**（每境 1 张主视觉海报 + 王林立绘 Runtime 底）
6. **asset-manifest.json** 建立（引擎只认 manifest，缺失自动 fallback）→ schema 见 `workers\asset-manifest.schema.json`
7. **CSS/Canvas 破境转场** demo（1~2 秒官方镜头 + 光效 + 新海报浮现）

**引擎不被资产卡住**：manifest 的 `fallback_realm` + `transition_video:null` 让缺失资产自动降级为 CSS 转场。

## 六、风险提醒（GPT 原文核心）

- 4K 不代表能用：动画帧多有运动模糊/景深/字幕 → 必须挑帧
- 超分别过度：王林眼睛/发丝最容易被 AI 重置「画脸」
- RIFE 补帧在快速法术/粒子处易出奇怪中间帧
- 桌面转场超 3~5 秒会烦 → 控制在 1~2 秒
- 原声多轨混杂：对白/BGM/环境常混一条 → 先拆 stems 再整理
- 透明视频（WebM Alpha）比角色分层图更吃存储/解码 → 优先用分层 PNG
- 必须记 Metadata（来源集数/时间码），否则以后找不到原镜头
