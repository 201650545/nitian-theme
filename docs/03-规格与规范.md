# 项目规格与规范（逆天主题）

> 通用规范见 **handbook v1.0**：https://github.com/201650545/handbook
> 规则优先级：本项目 override > 本文件 > handbook 默认规范。本文件只写本项目特有约束。

## 出图规格（形态矩阵标准）

- 构图：单人物全身立绘，居中，竖构图（2:3）；纯白背景；无文字、无水印、无边框
- 生成方式：图生图，以底图为锚（底图对应表见下）
- 增量元素：以任务清单（batch_items）逐项为准，禁止自由发挥

## 命名规则

- 角色形态：`系统名_状态名.png`（中文），如 `王林_筑基修士.png`
- 物件：`天逆珠_状态名.png`
- 底图/中间产物：英文代号（如 `01_wanglin_baiyi.png`），不入 git
