# 逆天主题 · 编年史彩蛋爬取任务书 v2（派工给快速模型）

> 执行者：快速模型 Agent（需具备联网搜索 + 网页读取能力，可用 opencli/搜索 API）
> 派工方：主 Agent（验收主管）
> 版本：2026-08-25
> 产出落 `D:\游戏\逆天主题\workers\`，写完汇报 `workers\汇报-编年史彩蛋.md`，主管自取。

---

## 一、目标

爬取并结构化《仙逆》（耳根小说 + 腾讯动漫官方动画）的**全故事线趣味内容**，供 DSH「逆天主题」引擎做彩蛋融合。已有底稿 `workers\T2-编年史底稿.json`（112KB，先读它，在其基础上增补，不要从零重写）。

## 二、要爬什么（六维信息 × 24 境界）

按引擎的 24 境天梯组织（凝气→筑基→结丹→元婴→化神→婴变→问鼎→阴虚阳实→窥涅→净涅→碎涅→空涅→空灵→空玄→空劫→踏天一桥~九桥），每个境界采集：

| 维度 | 说明 | 示例 |
|---|---|---|
| **大事件** | 该境界期 2-4 个关键剧情节点（一句话+50字概述） | 铁柱峰夺舍之战 |
| **敌人** | 该期对手：名字+身份+交手结果+一句趣味点评 | 藤化元：被王林当磨刀石，反复杀 |
| **法宝/机缘** | 该期获得/使用的法宝与机缘：名称+来历+能力 | 天逆珠：恒岳山所得，可时间回溯 |
| **友人** | 该期重要人物：名字+关系+结局一句话 | 李慕婉：炼丹天才，命运最令人意难平 |
| **名场面** | 最值得做成演出的 1 个场面（画面描述，供视频/演出参考） | 百万人头塔前一人镇一城 |
| **彩蛋/趣梗** | 书粉才懂的梗、语录、反差点（越多越好，每期≥2条） | "王林麻衣如雪"？错，是他师父 |
| **语录** | 该期 1-2 句原著/动画经典台词（注明出处章节/集数） | 「顺为凡，逆则仙」 |

## 三、输出格式（严格 JSON，引擎直接消费）

写两个文件：

### 1. `workers\编年史彩蛋.json`

```json
{
  "updated": "2026-08-XX",
  "sources": ["来源1URL", "来源2URL"],
  "realms": {
    "01_ningshi": {
      "events": [{"title": "...", "summary": "..."}],
      "enemies": [{"name": "...", "who": "...", "result": "...", "fun": "..."}],
      "treasures": [{"name": "...", "origin": "...", "power": "..."}],
      "friends": [{"name": "...", "relation": "...", "fate": "..."}],
      "scene": "名场面画面描述",
      "eggs": ["彩蛋1", "彩蛋2"],
      "quotes": [{"text": "...", "src": "出处"}]
    },
    "02_zhuji": { "...": "同结构" }
  }
}
```

境界 key 必须用引擎 id：`01_ningshi, 02_zhuji, 03_jiedan, 04_yuanying, 05_huashen, 06_yingbian, 07_wending, 08_yinyang, 09_kunie, 10_jingnie, 11_suinie, 12_kongnie, 13_kongling, 14_kongxuan, 15_kongjie, 16_qiao1 ... 24_qiao9`（踏天各桥剧情少可合并写，允许 `16_qiao1` 到 `24_qiao9` 引用同一组内容，但 key 都要有）。

### 2. `workers\编年史图片清单.json`

每境界 2-3 张**官方动画截图/海报**的候选图片 URL（来源限：仙逆动画官微、腾讯视频、B站官方、豆瓣剧照），格式：

```json
[{"realm": "01_ningshi", "url": "https://...", "desc": "画面描述", "source": "来源"}]
```

只收集 URL 清单，**不下载**（主管验收后统一下载转格式）。

## 四、纪律

1. **先读底稿**：`T2-编年史底稿.json` 已有编年史骨架，增补六维信息，别推翻重写
2. **事实优先**：以原著小说+官方动画为准，百科类站点（百度百科/萌娘百科/维基）可交叉验证；不确定的标注 `"verified": false`
3. **趣味性优先**：彩蛋/趣梗宁多勿缺，这是本任务的核心价值；书粉梗、名场面梗、王林的"苟"与"狠"的反差都算
4. **JSON 必须合法**：写完用 `python -c "import json;json.load(open(r'...',encoding='utf-8'))"` 自检
5. 凭证/密钥绝不写入任何产出文件
6. 全部完成后写 `workers\汇报-编年史彩蛋.md`：完成了哪些境界、多少条彩蛋、图片来源数、遗留缺口

## 五、验收标准（主管验收）

- 24 个境界 key 齐全，六维字段非空（踏天各桥可合并但要有）
- 彩蛋总数 ≥ 50 条，语录 ≥ 30 条，敌人 ≥ 25 个，法宝 ≥ 20 个
- JSON 可被 python json.load 无错解析
- 图片清单 ≥ 40 条 URL 且来源可追溯
