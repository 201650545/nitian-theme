# 拆动画四库 · 命令手册（落地用）

> ⚠️ **本手册为「有 4K 片源才启用」的可选分支。** 当前主线是「官方图锚点 + AI 生成」，见 `AI生成手册-官方图锚点版.md`。以下内容仅当拿到整集片源时再用。
> 适用于 D:\逆天主题\assets\ 骨架。所有命令为示例，路径/时间码按实际改。
> 前置：FFmpeg（ffmpeg/ffprobe）、可选 Upscayl / Real-ESRGAN-ncnn-vulkan / rembg / ImageMagick。

## 1. Frame Bank 抽帧

### 全片粗略索引（每 2 秒一帧，先建索引）
```bash
ffmpeg -i episode.mp4 -vf "fps=1/2" framebank/index/frame_%06d.jpg
```

### 重点镜头精确抽（指定时间码，质量 q:v=1）
```bash
ffmpeg -ss 00:18:42.500 -i episode.mp4 -frames:v 1 -q:v 1 wanglin_yuanying_001.png
```

### 抽帧后去字幕/裁切可选
```bash
# 裁剪顶部/底部字幕带，例：去底部 15%
ffmpeg -i in.png -vf "crop=iw:ih*0.85:0:ih*0.15" out.png
```

## 2. Audio Bank 拆音轨

### 拆整轨 WAV（保留 24bit）
```bash
ffmpeg -i episode.mp4 -vn -acodec pcm_s24le episode_audio.wav
```

### 分离 BGM/人声（用 demucs 或 UVR，PowerShell 调 demucs）
```bash
# demucs 分离 人声/伴奏 4 stems
demucs --two-stems=vocals episode_audio.wav -o audiobank/stems
```

### 转运行时格式（Opus 高压缩）
```bash
ffmpeg -i master.wav -c:a libopus -b:a 96k runtime.opus
```

## 3. Shot Bank 剪镜头

### 按时间码剪 2~10 秒片段（精确切需重编码）
```bash
# ss 截起点，t 时长；-c:v libx264 重编码以便从非关键帧切入
ffmpeg -ss 00:12:00 -i episode.mp4 -t 6 -c:v libx264 -crf 18 -vf scale=1920:1080 wl_yuanying_breakthrough_001.mp4
```

### 无缝循环（氛围背景）
```bash
# 拼接自身（适合可循环环境镜头）
ffmpeg -stream_loop 2 -i loop.mp4 -c copy out.mp4
# 或交叉淡化循环（更自然，需写 filter）——先截首尾再 xfade
```

### 静音镜头（当氛围背景用）
```bash
ffmpeg -i in.mp4 -an -c:v copy silent.mp4
```

## 5. 画质工具（后端）

### 超分（Real-ESRGAN-ncnn-vulkan）
```bash
realesrgan-ncnn-vulkan -i in.png -o out.png -s 4 -n realesrgan-x4plus
```

### 抠像（rembg 去背景，立绘/法宝用）
```bash
rembg i wanglin_raw.png wanglin_cutout.png
```

### 转 WebP Runtime
```bash
magick input.png -quality 85 -define webp:method=6 output.webp
```
（或 `ffmpeg -i in.png out.webp`）

### 补帧（RIFE，谨慎用于快速法术/粒子）
```bash
rife-ncnn-vulkan -i in.mp4 -o out.mp4 -n 3
```

## 7. 常用 ffprobe（查素材信息）
```bash
ffprobe -v error -show_entries format=duration,size -of default=noprint_wrappers=1 episode.mp4
```

## 注意
- Master 永不覆盖：改动只新增版本号。
- 所有镜头必须记 Metadata（来源集数 + 时间码），否则无法回溯原镜头。
- ffmpeg 长命令在 Windows 命令行有解析坑：路径含中文用 `-i` 传全路径即可；复杂 filter 建议写进 .bat/.ps1 或用 `-filter_complex_script`.
