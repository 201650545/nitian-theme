## 五、AGNES 视频 API 调用规范

| 项    | 值                                                                                                |
| ---- | ------------------------------------------------------------------------------------------------ |
| Base | `https://apihub.agnes-ai.com/v1`                                                                 |
| 模型   | `agnes-video-2.5-flash`                                                                          |
| mode | `text`                                                                                           |
| 提交   | `POST /videos`，body `{"model":"agnes-video-2.5-flash","mode":"text","prompt":"<完整提示词>"}`，返回 `id` |
| 轮询   | `GET /videos/{id}`，`status` = `completed` / `failed` / `cancelled`                               |
| 下载   | `completed` 后从 `metadata.url` 下载存为输出文件名                                                          |

**密钥读取（严禁外传/严禁明文入脚本/入库）**：从 `D:\项目\data\search_gateway\channels.json`（UTF-8 BOM）读 `keys.agnes`，运行时读取，脚本内只写路径不写密钥。

**限流与配额**：AGNES 为免费通道，可能逐日限流。提交前先探测配额，被拒（429/额度耗尽）时**不要重试轰炸**，改为分批：每批 5 境，批间 sleep 30s；失败清单记入汇报，允许换时段续跑。

## 六、批量脚本要求

在 `D:\逆天主题\workers\gen_bt_style_demos.py` 基础上改造为新脚本 `workers\gen_bt_batch.py`，要求：

1. 内置第三节 27 境配置表（realm\_id/名称/档位/输出文件名/主色/焦点意象）；
2. 按模板（第四节）自动组装每境提示词，逐境提交；
3. **断点续跑**：输出文件已存在且 >500KB 则跳过；已有 `bt_m/bt_b/bt_t/bt_p` 旧版**必须重新生成覆盖**（属本次 2D 动漫风格替换，跳过它们不算完成）；
4. 每境打印 `提交 id → 轮询状态 → 保存大小`；失败记入 `failed` 清单；
5. 全跑完打印 `DONE n/total + failed 清单`；脚本幂等可重跑。
