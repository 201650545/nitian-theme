## 项目结构

- `docs/` 知识库（本仓事实源）：核心 00–04 四件套 + `05-成果与预览` `06-项目结构` + 专题层 `10-制作需求/` `20-设计与架构/` `90-归档/`
- `workers/` 资产生产工作区（生产/采集/校验脚本 + 契约；缓存/待验收/日志不入库）
- `assets/` 游戏内引用资产（成品图/视频/GLB 不入库）
- `preview/` 成果展示层（README/代表性截图入库；全量预览不入库）
- `dsh-plugin/` DSH 插件
- `tools/` 协作/采集工具脚本（与生产管线分离）
